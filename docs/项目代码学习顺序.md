# 项目代码学习顺序（从 0 到能讲、能改）

> 目标：**能看懂主流程、能改小功能、面试能讲清楚**——不是把每一行都背下来。  
> 按本文顺序学；每天做完「三步验证」。  
> 建议总时长：**4～6 周**（每天 1.5～2 小时）。再短容易囫囵吞枣。

对应仓库结构（学的时候看这些目录）：

- `frontend/` — 浏览器侧（组件、hooks、算法与本地存储）
- `backend/` — 服务器业务逻辑
- `app/` — Next.js 页面入口与 API 薄路由（框架要求，必须留在根目录）

---

## 总原则（每学一个文件都做这 3 步）

1. 用自己的话写一句：「这个文件干什么」
2. 找它被谁调用（看 import）
3. 改一个极小东西验证（文案 / `console.log` / 改个默认分钟数）

---

## 第 0 周（2～3 天）：语言底子

否则后面代码读不动。

| 学什么 | 到什么程度 |
|--------|------------|
| JS | 变量、函数、数组、对象、`async/await`、`fetch` |
| TS | 能认 `type` / `interface`，不报错就行 |
| React | 组件、`useState`、`useEffect`、props |
| Next 常识 | `app/page.tsx` = 路由；`app/api` = 接口 |

不必另开大课，边查边对着项目看。

---

## 第 1 周：数据长什么样 + 核心算法（面试最爱问）

| 顺序 | 文件 | 你要搞懂 |
|------|------|----------|
| 1 | `frontend/lib/types.ts` | Course、PlanDay、进度结构 |
| 2 | `frontend/lib/config.ts` | 常量从哪来 |
| 3 | `frontend/lib/bvid.ts` | 怎么从粘贴文本抠出 BV |
| 4 | `frontend/lib/format.ts` | 时长/封面怎么格式化 |
| 5 | **`frontend/lib/planner.ts`** | **怎么按每天分钟数切成课表**（重点） |
| 6 | `frontend/lib/plan-normalize.ts` | 旧数据怎么洗成统一格式 |
| 7 | 对应 `*.test.ts` | 测例帮你理解边界情况 |

**本周面试稿：**  
「用户设定每天学多久，我按视频时长顺序装进每天，生成 day1、day2…」

---

## 第 2 周：主流程页面（用户点下去发生了什么）

| 顺序 | 文件 | 你要搞懂 |
|------|------|----------|
| 1 | `app/layout.tsx` + `app/page.tsx` | 入口怎么挂上壳子和首页 |
| 2 | `frontend/components/layout/AppShell.tsx` | 全局 Provider、顶栏底栏 |
| 3 | `Topbar.tsx` / `SiteFooter.tsx` | 导航、打赏入口 |
| 4 | **`PlanPage.tsx`** | **总控：拉课、生成计划、存进度** |
| 5 | `LandingHero.tsx` | 粘贴链接、设置分钟/天数/倍速 |
| 6 | `PlanSettingsRow.tsx` | 设置 UI |
| 7 | `ResultsPanel.tsx` | 课表怎么展示、打卡 |
| 8 | `plan-utils.ts` / `LoadingOverlay` / `CardDownload` / `CoverImage` | 辅助与导出 |

**本周面试稿：**  
「从前到后：粘贴 → 解析 BV → 请求课程 → planner 生成 → 展示与打卡」

## 第 3 周：前端请求 + 本地存储 + 登录态

| 顺序 | 文件 | 你要搞懂 |
|------|------|----------|
| 1 | `frontend/lib/bilibili-client.ts` | 前端为何调自己的 `/api/bilibili` |
| 2 | `frontend/lib/storage.ts` | localStorage 怎么存进度 |
| 3 | `frontend/lib/auth-client.ts` / `auth-local.ts` | 登录请求与本地会话 |
| 4 | `frontend/hooks/useAuth.tsx` | 全局登录态 |
| 5 | `useToast.tsx` / `useUiStore.tsx` | 提示与弹窗状态 |
| 6 | `AuthModalHost.tsx` | 登录注册 UI |
| 7 | `cloud-sync.ts` | 登录后如何和云端合并 |
| 8 | `course-restore.ts` + `MinePageClient.tsx` + `app/mine/page.tsx` | 「我的课程」怎么恢复 |

**本周面试稿：**  
「进度先落本地；登录后和云端 merge，避免覆盖丢打卡」

---

## 第 4 周：后端整条链（能讲清为什么要有服务端）

| 顺序 | 文件 | 你要搞懂 |
|------|------|----------|
| 1 | `app/api/*/route.ts`（auth / bilibili / sync / feedback / health） | 薄入口，只转发 |
| 2 | `backend/bilibili-proxy.ts` | 代理 B 站、躲 CORS/限流 |
| 3 | `backend/db.ts` | 怎么连数据库 |
| 4 | `backend/user-repository.ts` | 用户/课程表读写 |
| 5 | `backend/auth-service.ts` | 注册登录、token |
| 6 | `backend/sync-service.ts` | 推拉同步逻辑 |
| 7 | `backend/feedback-service.ts` | 反馈怎么存 |
| 8 | `FeedbackFab` / `TipModal` / `admin/feedback` | 反馈与打赏、管理页 |

**本周面试稿：**  
「B 站不能浏览器直连所以服务端代理；账号与进度在 Postgres；JWT/HMAC 鉴权」

---

## 第 5 周：部署 + 口述 + 小改动（可与第 4 周末合并）

| 做什么 | 标准 |
|--------|------|
| 复述 Nginx → Next → API → DB | 2 分钟不卡 |
| 复述规划算法 | 能画「视频列表 → 按天装」 |
| 自己改 2～3 个小功能 | 如默认分钟、文案、页脚 |
| 走一遍：解析课 → 打卡 → 登录同步 | 全流程亲手点 |

部署口令记住即可：`git pull` → `npm run build` → `pm2 restart`（详见 `docs/改代码后部署流程.md`）。

---

## 建议总时长

| 节奏 | 每天 | 学完到「能讲能改」 |
|------|------|-------------------|
| **推荐** | 1.5～2 小时 | **约 5 周** |
| 抓紧 | 2.5～3 小时 | **约 3.5～4 周** |
| 太赶 | 想 2 周啃完 | 容易只会背词，一追问就崩 |

若离暑假实习还有约 6 个月：前面 **1～1.5 个月** 把本项目吃透即可；其余时间复盘、面试题与其它副线。

---

## 「每一个都要学」但有优先级

- **必须讲透：** `planner.ts`、`PlanPage.tsx`、`bilibili-proxy.ts`、`auth-service.ts`、`sync-service.ts`、`storage.ts`
- **必须过一遍：** 上文表格里列出的其它业务文件
- **可快读：** 纯 UI 样式、测试文件（测例当说明书）
- **先别深挖：** `legacy/`、过细的运维脚本（会说部署三步即可）

---

## 今天就可以开始的第 1 课

1. 打开 `frontend/lib/types.ts`（约 20 分钟）
2. 打开 `frontend/lib/planner.ts`，对着函数名读一遍（约 40 分钟）
3. 写 5 句话笔记：「输入是什么、输出是什么、每天装不下怎么办」

看完把笔记拿来对照纠偏，再进入下一个文件。
