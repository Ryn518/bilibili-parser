# 技术名词一句话词典（先读这个）

> 每个词用大白话说明「它是干嘛的」，不用背定义，能联想到你项目里哪块就行。

## 基础概念

| 名词 | 一句话 |
|------|--------|
| **浏览器** | 用户打开网页用的软件（Chrome 等），负责显示页面、执行网页里的 JS。 |
| **服务器** | 一台 24 小时开着、对外提供网站的电脑（你的腾讯云就是）。 |
| **HTTP** | 浏览器和服务器「说话」的规则，比如「给我首页」「提交登录表单」。 |
| **URL** | 网址，告诉浏览器要去哪，如 `http://122.51.12.86/mine?course=BVxxx`。 |
| **域名** | 网址里好记的名字（kebiaoplan.cn），背后指向服务器 IP。 |
| **DNS** | 把域名翻译成 IP 的「电话簿」，备案没通过时可能显示拦截页。 |
| **备案** | 在中国大陆用域名对外服务需向工信部登记，没备案域名可能被拦。 |
| **HTTPS / SSL** | 加密的 HTTP，地址栏有小锁，防密码被偷听；备案后一般会配证书。 |
| **前端** | 用户在浏览器里看到和点击的部分（页面、按钮、课表）。 |
| **后端** | 在服务器上跑、用户看不见的逻辑（登录校验、存数据库、调 B 站）。 |
| **全栈** | 前端 + 后端都会一点，你这个项目就是典型全栈小项目。 |
| **API** | 前后端约定的「接口」：前端发请求，后端返回 JSON 数据。 |
| **JSON** | 一种文本格式，像 `{ "name": "fzh", "bvid": "BVxxx" }`，前后端常用它传数据。 |
| **CORS** | 浏览器安全限制：网页不能随便调别的网站 API，所以你要用自家后端代理 B 站。 |
| **环境变量 (.env)** | 密钥、数据库地址等配置，写在服务器文件里，**不提交到 Git**。 |

## 页面与样式

| 名词 | 一句话 |
|------|--------|
| **HTML** | 网页的骨架：标题、输入框、按钮用什么标签搭出来。 |
| **CSS** | 网页的长相：颜色、间距、手机/电脑怎么排版。 |
| **Tailwind CSS** | 用很多小 class（如 `flex gap-4`）快速写样式，不用单独写一大段 CSS 文件。 |
| **JSX** | 在 JS 文件里写「像 HTML 的标签」，React 专用写法。 |
| **响应式** | 同一页面在手机和电脑上都能正常看，靠 flex、宽度断点等实现。 |

## 编程语言与工具

| 名词 | 一句话 |
|------|--------|
| **JavaScript (JS)** | 浏览器和 Node 里运行的语言，你项目里绝大部分逻辑都是它。 |
| **TypeScript (TS)** | 带类型的 JS，写错类型编辑器会提醒，大项目少踩坑。 |
| **Node.js** | 让 JS 能在服务器上跑，Next.js 和 PM2 都跑在它上面。 |
| **npm** | Node 的包管理器，`npm install` 装依赖，`npm run dev` 启动开发。 |
| **Git** | 记录代码每次改了什么，能回退、能 push 到 GitHub。 |
| **GitHub** | 放代码的远程仓库，你服务器 `git pull` 就是从这里拉最新版。 |

## React 相关

| 名词 | 一句话 |
|------|--------|
| **React** | 用「组件」拼页面的库，数据变了页面自动更新，不用自己改 DOM。 |
| **组件** | 可复用的一小块 UI，如顶栏、输入框、课表一行。 |
| **props** | 父组件传给子组件的数据，只读。 |
| **state (useState)** | 组件内部会变的数据，如「当前课表、是否登录」。 |
| **useEffect** | 在「渲染之后」做副作用，如登录后拉进度、读 URL 参数恢复课程。 |
| **Context** | 跨多层组件共享数据，如全局登录态、课表上下文，不用一层层传 props。 |
| **useRef** | 存一个可变引用，常用在「防止 effect 重复执行把页面清空」这类场景。 |
| **Hook** | `useState`、`useEffect` 这类以 `use` 开头的函数，给函数组件加能力。 |

## Next.js 相关

| 名词 | 一句话 |
|------|--------|
| **Next.js** | 基于 React 的全栈框架：既有页面路由，也能写 API，还能 build 部署。 |
| **App Router** | Next.js 13+ 的路由方式：`app/page.tsx` 就是首页，`app/mine/page.tsx` 就是 `/mine`。 |
| **layout** | 包住多个页面的公共外壳，如顶栏、底栏、全局样式。 |
| **page** | 某个路由对应的页面内容。 |
| **'use client'** | 标记这个文件在浏览器里跑，能用 useState 等；没标记的默认偏服务端。 |
| **API Route / Route Handler** | `app/api/xxx/route.ts`，写 GET/POST 接口，相当于小型后端。 |
| **SSR / CSR** | 服务端渲染 vs 浏览器渲染；你项目很多交互页是客户端渲染（'use client'）。 |
| **build** | `npm run build` 把项目编译成生产版，服务器上跑的是 build 后的结果。 |

## 本项目业务

| 名词 | 一句话 |
|------|--------|
| **BV 号** | B 站视频/合集的唯一 ID，如 `BV1xx411c7mD`，从用户粘贴的链接里解析出来。 |
| **分 P** | 一个合集里的每一集视频，规划算法按每 P 的时长切天。 |
| **planner（规划算法）** | 按「每天学多少分钟」把视频顺序切成 day1、day2… 的核心逻辑。 |
| **localStorage** | 浏览器里长期存数据，关掉浏览器还在；你用来存登录用户的课表进度。 |
| **sessionStorage** | 浏览器里「本次打开标签页」有效，访客模式用它，关标签就清。 |
| **planSnapshot（快照）** | 生成课表时存一份完整 plan，以后不用重新调 B 站也能打开旧课。 |
| **云同步** | 登录后把本地进度和 Supabase 数据库对齐，换设备也能接着学。 |
| **merge（合并）** | 本地和云端都有进度时，按规则合在一起（如打卡天数取并集），避免覆盖丢数据。 |

## 后端 · 数据库 · 安全

| 名词 | 一句话 |
|------|--------|
| **REST** | 用 URL + HTTP 方法（GET 查、POST 增、PUT 改、DELETE 删）设计 API 的常见风格。 |
| **Bearer Token** | 登录后发的一串凭证，以后请求在 Header 里带上，证明「我是 fzh」。 |
| **密码哈希** | 注册时把密码变成不可逆的乱码存库，即使数据库泄露也看不到明文密码。 |
| **JWT / HMAC** | 一种签名 token 的常见做法；你项目用 HMAC + AUTH_SECRET 签发登录凭证。 |
| **PostgreSQL** | 一种关系型数据库，用 SQL 存表；Supabase 底层就是它。 |
| **Supabase** | 提供托管 PostgreSQL + 控制台的服务，你免费 tier 存用户和课程进度。 |
| **SQL** | 操作数据库的语言，如 `SELECT * FROM users WHERE username = 'fzh'`。 |
| **JSONB** | PostgreSQL 里存 JSON 的列类型，你的 `plan_snapshot` 就存这里。 |
| **主键 / 外键** | 主键唯一标识一行；外键把两张表关联（如 user_courses.user_id 指向 users）。 |
| **DATABASE_URL** | 连接 Supabase 数据库的一串地址，写在 `.env` 里。 |

## 运维与部署

| 名词 | 一句话 |
|------|--------|
| **Linux** | 服务器常用操作系统，你用 Ubuntu，通过 WebShell/SSH 敲命令。 |
| **SSH / WebShell** | 远程登录服务器的方式，在网页或终端里操作云主机。 |
| **PM2** | Node 进程管理器：崩溃自动重启，用 `pm2 restart kebiaoplan` 发布新版本。 |
| **Nginx** | 放在最前面的「门卫」，用户访问 80 端口，它转发到你 Next.js 的 3000 端口。 |
| **反向代理** | Nginx 替后端接请求，用户只看到一个地址，不知道后面是 3000 端口。 |
| **部署 (deploy)** | 把新代码 build 并放到服务器跑起来：`git pull` → `npm run build` → `pm2 restart`。 |
| **健康检查** | `/api/health` 返回 ok，用来快速判断服务有没有挂。 |
| **备份 (pg_dump)** | 把数据库导出成文件，真出事可以恢复用户进度。 |

## 测试与其它

| 名词 | 一句话 |
|------|--------|
| **Vitest** | 跑单元测试的工具，验证 planner 等函数算对不对。 |
| **单元测试** | 自动测一个小函数，改代码后跑一遍，防止把算法改坏。 |
| **正则表达式** | 从字符串里按规则抠内容，如从粘贴文本里提取 BV 号。 |
| **Redis** | 内存缓存数据库，高并发时用；你 113 用户暂时用不上。 |
| **RLS** | Supabase 行级安全，限制「谁能读哪一行数据」，以后加固可用。 |

## 总览：项目技术地图

```
用户浏览器
    ↓
Next.js 页面 (app/ + components/)
    ↓
API 路由 (app/api/*)
    ↓
服务端逻辑 (lib/server/*)  ←→  PostgreSQL / Supabase
    ↓
B 站公开接口 (lib/server/bilibili-proxy.ts)
```

**面试一句话：**  
「Next.js 全栈 App，前端 React 做课表交互，API Route 代理 B 站数据并处理登录，PostgreSQL 存用户和进度，浏览器 localStorage 做缓存和离线副本，腾讯云 + PM2 部署。」

## 学英语 —— 给你具体「为了什么」（才有动力）
